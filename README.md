# Johan Boza — Portafolio freelance

Landing page profesional de Johan Boza, desarrollador Full Stack en San Vito, Puntarenas, Costa Rica.

El sitio presenta servicios de desarrollo web, proyectos destacados, información de contacto y un mapa interactivo de la zona de trabajo.

## Tecnologías

- Next.js / React
- TypeScript
- Tailwind CSS
- Vinext + Vite

## Ejecutar localmente

Requiere Node.js 22.13 o superior.

```bash
npm install
npm run dev
```

Abre la dirección local que muestre la terminal.

## Comandos útiles

```bash
npm run dev      # inicia el entorno de desarrollo
npm run build    # genera y valida la compilación de producción
npm run lint     # revisa el código con ESLint
```

## Estructura

```text
app/
```
